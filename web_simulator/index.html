Scope and validation

This release adds a reference-free warm-started hybrid controller and a blind 2,700-realization inverse benchmark. The controller reproduces the cold SG/FV current to 3×10−12 at 0.165 s per state, 9.5-fold below a full 21×61 solve. The blind study uses shared noisy observations and shows that dual current-plus-selectivity inversion reaches 1.7% median charge error but only 68% 95% coverage at 1% noise, because a roughly 2% surrogate bias floor remains; the reversal potential is strongly state dependent (263% median error for weak charge versus 7.3% for strong charge). Single- and multi-salt current–voltage data still leave charge unidentifiable. The hyperbolic reparameterization keeps the charge identity exact to machine precision, and the exact float64 SG/FV Jacobian confirms the operator's log-log current sensitivity to radius to about 1.5×10−4. The released software is permanently archived at Zenodo DOI 10.5281/zenodo.23487404.

Live SG/FV reference solver

Runs the exact float64 Scharfetter–Gummel finite-volume reference in Python at the current slider parameters (~0.20 s). In the deployed portal the button calls the same-origin /api/solve_sg endpoint; locally it uses http://127.0.0.1:8765/api/solve_sg from scripts/serve_interactive.py.

The live solve is independent of the surrogate: it validates the operator by recomputing the benchmark current and the axial profile I(z) from first principles.
