Scope and validation

This release adds a trunk ablation, a data-scaling study on a 384-state solve expansion, a multi-protocol identifiability analysis, and a Stage-11 reviewer-upgrade study. The multi-scale radial trunk is a modest near-wall inductive bias rather than a necessity (a plain MLP trunk matches the net-charge field; the radial basis lowers the wall-gradient error by about 7%). In-distribution error follows an N−0.55 scaling law, while out-of-distribution error is nearly flat in the number of training states. A four-way constraint benchmark shows that the hyperbolic reparameterization matches the best projection scheme while keeping the charge identity exact to machine precision, and a physics-weight sweep places the default 10−3 at the Pareto point. A Fisher analysis and a 15-state, three-protocol inverse study show that the pore radius is recovered from a current–voltage curve to 0.46%, whereas wall charge is a flat direction below the noise floor unless an independent near-wall selectivity observable is added (then both are recovered to below 0.3%). A centered finite-difference Jacobian of the exact float64 solver confirms the operator sensitivity: the two agree on the log-log current sensitivity to radius to 1.5×10−4 and on the dual-protocol conditioning number to about 1%.

Live SG/FV reference solver

Runs the exact float64 Scharfetter–Gummel finite-volume reference in Python at the current slider parameters (~0.20 s). In the deployed portal the button calls the same-origin /api/solve_sg endpoint; locally it uses http://127.0.0.1:8765/api/solve_sg from scripts/serve_interactive.py.

The live solve is independent of the surrogate: it validates the operator by recomputing the benchmark current and the axial profile I(z) from first principles.
